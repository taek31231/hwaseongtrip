# 화성지질공원 야외지질 기록장

공룡알 화석지와 우음도 답사에서 학생이 직접 관찰을 기록하고, 끝나면 보고서를 PDF로 받아 가는 웹 기록장입니다. 서버 없이 정적 파일만으로 동작하고, 기록은 전부 학생 기기 안에만 저장됩니다.

## 올리는 방법

1. GitHub에 새 저장소를 만들고 이 폴더의 파일을 전부 올립니다.
2. 저장소 Settings → Pages → Source를 `Deploy from a branch`, 브랜치를 `main`, 폴더를 `/ (root)`로 지정합니다.
3. 몇 분 뒤 `https://<계정>.github.io/<저장소이름>/` 으로 열립니다.

경로는 모두 상대경로라 저장소 이름이 무엇이든 그대로 동작합니다.

## 폴더 구성

```
index.html        전체 코드 (화면, 기록 저장, 모형, 보고서)
manifest.json     홈 화면에 추가할 때 쓰는 앱 정보
sw.js             오프라인 캐시 (서비스 워커)
icon-192.png      홈 화면 아이콘
icon-512.png      홈 화면 아이콘
.nojekyll         GitHub Pages가 파일을 가공하지 않도록 하는 표시
assets/img/       지점 사진과 자료 사진
```

## 답사 전에 할 일

- **학생 안내**: 답사 전날 학교 와이파이에서 주소에 접속해 "홈 화면에 추가"를 하게 합니다. 그러면 현장에서 통신이 끊겨도 열립니다.
- **아이폰 주의**: 홈 화면 앱과 사파리는 저장 공간이 서로 다릅니다. 처음부터 끝까지 홈 화면 아이콘으로만 쓰도록 안내하세요.
- **수정했다면**: `sw.js` 맨 위 `CACHE` 값의 숫자를 올려야 학생 기기에서 새 버전으로 바뀝니다. 수정은 답사 전날까지 끝내는 편이 안전합니다.
- **끝난 뒤**: 보고서를 PDF로 저장하게 하고, 백업 파일(JSON)도 함께 받아 두게 하세요. 공용 기기를 쓴 경우 다음 사람을 위해 사진을 지우도록 안내합니다.

## 다른 답사에 쓰려면

`index.html` 안의 `const TRAIL = { ... }` 한 덩어리만 고치면 됩니다. 코드는 건드릴 필요가 없습니다.

```js
{
  id:"w1", name:"구부러진 바위",
  cover:"assets/img/cover-w1.webp",   // 이름 옆 작은 사진 (없어도 됨)
  intro:"위치 안내 한두 문장",
  keyq:"이 지점에서 붙잡을 질문 하나",
  safety:"안전 유의사항",              // 없어도 됨
  doing:"현장 활동 안내",               // 없어도 됨
  photos:["전경","노두","근접"],        // 사진 칸 이름
  sketch:true,                        // 스케치 칸을 둘지
  interps:[                           // 해석 질문들
    {id:"i1", label:"질문 문장"},
    {id:"i2", label:"질문 문장",
     figures:[{src:"assets/img/....webp", caption:"사진 설명"}]},
    {id:"i3", label:"남은 의문"}
  ]
}
```

- 튜토리얼처럼 블록을 나누려면 `kind:"tutorial"`과 `blocks:[...]`를 씁니다.
- 지점 id는 저장 키로 쓰이니 한 번 정한 뒤에는 바꾸지 마세요. 바꾸면 그 지점에 쓴 기록을 못 찾습니다.
- 저장 키 전체를 새로 시작하려면 `const KEY=...`의 버전 숫자를 올립니다.
- 사진을 추가하면 `sw.js`의 `FILES` 목록에도 경로를 넣어야 오프라인에서 보입니다.

### 특수 기능

| 설정 | 하는 일 | 지금 쓰는 곳 |
| --- | --- | --- |
| `model:"fault"` | 상반·하반·상반 세 덩어리를 끌어 단층을 맞추는 모형 | 잘린바위 |
| `model:"imbrication"` | 물 흐름을 바꾸면 자갈이 기울어 눕는 모형 | 도랑바위 |
| `modelAsk:{id,label}` | 모형 바로 아래에 붙는 서술 칸 | 도랑바위 |
| `tool:"distance"` | 항공사진 위 GPS 핀 표시와 거리 재기 | 알바위 |

항공사진 좌표 변환은 `TRAIL.map`에 들어 있습니다. 다른 지역 사진으로 바꾸려면 기준점 세 곳 이상의 위경도로 아핀 변환 계수를 다시 구해 `lat`, `lon` 값을 교체하세요.

## 학생 기록은 어디에 저장되나

- 글은 브라우저 `localStorage`, 사진과 스케치는 `IndexedDB`에 들어갑니다. 서버로 전송되지 않고 교사도 볼 수 없습니다.
- 그래서 **기기를 바꾸거나 브라우저를 바꾸면 기록이 보이지 않습니다.** 백업 파일 내보내기를 꼭 안내하세요.
- 온라인 제출이나 AI 피드백 같은 기능을 추가해 기록을 외부로 보내려면, 개인정보 수집·이용 동의와 학교 절차를 먼저 확인해야 합니다.
